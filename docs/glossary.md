# Глоссарий. ИС управления автосервисом

## Описание предметной области

Автосервис (станция технического обслуживания, СТО) выполняет работы по ремонту и обслуживанию автомобилей. Основной цикл работы выглядит так:

1. Клиент записывается на обслуживание или приезжает без записи.
2. Мастер-приёмщик осматривает автомобиль, фиксирует жалобы и оформляет **заказ-наряд**.
3. Проводится **диагностика** — определяется перечень необходимых работ.
4. Составляется смета (работы + запчасти), клиент её согласовывает.
5. Механики выполняют работы по наряду, списывая запчасти со склада.
6. После завершения формируется счёт, клиент оплачивает и забирает автомобиль.

Система призвана автоматизировать учёт клиентов, автомобилей, заказов-нарядов, выполняемых работ и расхода запчастей, а также сократить ручную бумажную работу мастеров и приёмщиков.

## Участники

| Роль | Описание |
|---|---|
| **Клиент** | Физическое или юридическое лицо, владелец автомобиля, заказывающий работы |
| **Мастер-приёмщик** | Сотрудник, принимающий автомобиль, оформляющий заказ-наряд и согласующий смету с клиентом |
| **Механик (мастер)** | Сотрудник, выполняющий работы по заказ-наряду |
| **Управляющий** | Руководитель сервиса, заинтересован в отчётности: загрузка, выручка, остатки склада |

## Термины

| Термин | Определение |
|---|---|
| **Заказ-наряд** | Основной документ сервиса: фиксирует автомобиль, клиента, перечень работ, запчасти, стоимость и статусы выполнения |
| **Автомобиль** | Транспортное средство клиента. Учитывается по VIN, марке, модели, году выпуска, госномеру и пробегу |
| **VIN** | Уникальный идентификационный номер автомобиля (17 символов) |
| **Работа** | Единица услуги сервиса (например, «замена масла», «диагностика подвески»). Характеризуется наименованием, ценой и нормо-часами |
| **Нормо-час** | Единица трудоёмкости работы: сколько времени занимает выполнение по нормативу |
| **Запчасть** | Материальный ресурс, используемый при выполнении работ (масло, фильтр, тормозные колодки) |
| **Номенклатура** | Справочник запчастей и работ, используемых в сервисе |
| **Склад** | Место хранения запчастей. Ведётся учёт остатков и списаний по заказ-нарядам |
| **Диагностика** | Этап определения неисправностей и состава работ. Может быть платной и бесплатной |
| **Смета** | Согласованный перечень работ и запчастей с ценами в рамках заказ-наряда |
| **Статус заказ-наряда** | Текущее состояние наряда: «принят», «в работе», «ожидает согласования», «готов», «выдан» |
| **Счёт (инвойс)** | Документ на оплату, формируется по завершении работ |
| **Гарантия** | Обязательство сервиса бесплатно устранить повторную неисправность в течение срока на выполненные работы и запчасти |
| **Запись на обслуживание** | Предварительное бронирование даты и времени приёма автомобиля |
| **Пробег** | Показания одометра на момент приёма автомобиля. Учитывается в заказ-наряде |

## Источники терминов

Определения составлены на основе типовой практики работы автосервисов средней полосы России;[^1] термины «заказ-наряд», «нормо-час», «номенклатура» применяются в стандартных учётных системах (1С:Автосервис, CRM СТО) в аналогичных значениях.

[^1]: Внутренние нормативные материалы и наблюдения автора в процессе проектирования системы.
