# ИС автосервиса

Пет-проект: проектирование и MVP информационной системы для управления автосервисом (СТО).

## О проекте

Система для автоматизации работы автосервиса: учёт клиентов, автомобилей, заказов-нарядов, выполняемых работ и расхода запчастей. Работы ведутся от постановки задачи до работающего прототипа.

## Цели проекта

- Показать полный цикл проектирования ИС: сбор требований, моделирование (UML, BPMN), проектирование базы данных и API.
- Реализовать минимальный рабочий прототип (MVP) на основе спроектированной модели.
- Вести документацию в формате, приближенном к реальным проектам: глоссарий, требования, сценарии использования, SRS.

## Структура репозитория

```
docs/          — документация: глоссарий, требования, сценарии, SRS, диаграммы
db/            — схема базы данных (DDL)
api/           — спецификация OpenAPI и MVP-приложение
postman/       — коллекция запросов
```

Структура наполняется по мере развития проекта.

## Стек

- PostgreSQL
- Python / FastAPI
- OpenAPI 3.0, Postman
- Draw.io (диаграммы UML, BPMN, ER)
- Git/GitHub
